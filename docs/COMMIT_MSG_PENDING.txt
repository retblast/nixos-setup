  paths (MoreWaita does not inherit Adwaita)
- shell-theme: barHeight/dockHeight/iconDir tokens
- battery icon: adwaita 50.0 renamed level 100 to -charged-symbolic (no

  idle; a mapped layer window swallowed dock pointer input even while
  fully transparent (verified via hyprctl layers)
- float mode per workspace: float-workspace script (fish) toggles
  togglefloating per window on the active workspace, records the state
  in marker files ($XDG_RUNTIME_DIR/hypr-float-ws) and pokes the shell
  over IPC (quickshell ipc call floatws set). Bound to SUPER SHIFT F.
  Hyprland 0.56 notes: workspaceopt is a deprecated no-op, workspace
  rules lost all:float, setfloating is a no-op, togglefloating works
- dock visibility follows float mode: hidden on tiling workspaces,
  shown on floating ones. quickshell 0.3.1 focusedWorkspace never
  updates after startup, so the active workspace is probed from
  hyprctl at start and tracked via Hyprland.rawEvent (event data is
  the value after >>: workspace>>77 -> "77"); a shell restart re-syncs
  float state from the marker dir
